About this prototype

This is a minimally functional prototype built for academic demonstration. It uses Tesseract.js (client-side OCR) to read text from an uploaded photo and compares it against the expected identifier. The operator name is mandatory so that each verification is associated with the person performing the physical media rotation.

The prototype simulates the AI Verification Engine described in the AudiTag invention disclosure: image verification, identifier extraction, policy comparison, confidence-based routing and human review for uncertain cases.
