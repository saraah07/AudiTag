About the AudiTag Prototype

AudiTag is a feasibility prototype designed to address a specific gap in backup operations: a manual checklist can show that a Night Auditor reported completing a tape rotation, but it cannot independently prove that the correct backup media was actually inserted.

The prototype adds a simple verification step immediately after the physical tape rotation. The Night Auditor uploads a photo of the inserted backup media, enters the identifier expected from the rotation schedule, and records their name. AudiTag then reads the identifier from the image and compares it with the expected identifier.

Based on the verification, the prototype produces one of three outcomes: PASS when the expected media is verified, FAIL when a clearly different media identifier is detected, or UNCERTAIN when the image or identification is not reliable enough for an automatic decision.

For the Night Auditor, this provides immediate confirmation that the media rotation appears correct instead of relying only on a manual checklist. A wrong tape can therefore be identified during the same shift, before the backup process proceeds.

For the IT Coordinator and hotel management, AudiTag provides clearer and more traceable evidence of the verification. The operator's name and verification time are recorded with the result, while failed or uncertain cases can be referred to the IT Coordinator for human review. This supports more proactive error detection, stronger compliance records, and clearer accountability.

The prototype demonstrates the feasibility of converting a manual declaration into an evidence-based verification process while keeping the physical tape rotation and final responsibility with the human operator.

Prototype scope: This website demonstrates the core feasibility of the AudiTag solution using image-based text identification. It is an academic prototype and not a production deployment. A full implementation would additionally connect the verification process to the rotation-policy database, evidence repository, compliance dashboard, and formal user authentication.
